# Simple User API

REST API sederhana untuk manajemen data user, dibuat menggunakan Node.js + Express.

## Endpoints

- GET /users - Menampilkan daftar semua pengguna
- GET /users/:id - Menampilkan detail pengguna berdasarkan ID
- POST /users - Menambahkan pengguna baru

## Cara Menjalankan

npm install
node index.js

Server berjalan di http://localhost:3000
